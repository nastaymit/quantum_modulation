# Моделирование прохождения неклассического поляризованного света через фазовый модулятор 

**Магистерская диссертация:** «Моделирование прохождения неклассического поляризованного света через фазовый модулятор»  
**Автор:** Митрофанова Анастасия Сергеевна  
**Научный руководитель:** Попов Евгений Николаевич, к. ф. - м. н.

## Цель работы

Разработать квантовую модель фазовой модуляции многомодового неклассического поляризованного света и исследовать влияние фазовых флуктуаций на его динамику в системе последовательно расположенных модуляторов.

## Задачи

1. Рассмотреть модуляцию поляризованного света на основе существующей квантовой модели.
2. Провести поиск нетривиальных случаев модуляции многомодового неклассического света.
3. Реализовать моделирование динамики света, проходящего через серию модуляторов с учётом фазовых флуктуаций между ними.
